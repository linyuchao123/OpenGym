# 首页状态与手机通知（2026-11-03）

本次范围：紧凑首页、24 小时头像状态环、后台私信和按训练计划的手机推送。

## 行为

- 头像、问候语、日期和状态组成一个身份区；认识作者与设置位于右上角。小屏保留作者图标及可访问名称。设置按钮直接进入统一设置。
- 有效状态显示彩色头像环，在 24 小时到期、主动清除或设备唤醒发现过期时移除。主页、设置及社区的 Avatar 使用同一规则，不改变原头像图片。
- iPhone 普通浏览器标签页显示添加主屏幕的三步说明。主屏 Web App 中开启后，请系统授权；成功开启设备通知同时启用私信提醒，正文不进入锁屏推送。
- 计划提醒默认关闭，无默认强制发送时刻。成员自行选择每日时间和时区。后台读取最新训练计划、按日期覆盖、队列规则和已完成训练；休息日及当天相应训练已完成时跳过。保留独立的一次性提醒。
- 定时任务每分钟检查；清理素材和服务统计仍每五分钟执行。每轮最多处理两个待重试私信和两个到期训练提醒，限制外部推送请求数量。
- 训练提醒使用带到期时间的原子领取，避免并发 cron 重复发送。失败保留到期任务重试，超过一小时的训练提醒跳过。私信即时推送失败时只把收件路由元数据放入短期 outbox，最多重试五次、十分钟后过期；不存放私信正文，重试前复核开启状态。

## 验证

- 前端相关回归 221 项通过，包含首页、设置、通知进行状态和失败重试、私信开启、计划时间保存与关闭、iPhone 添加主屏提示、头像状态清除与 24 小时自动过期。
- Cloudflare 完整回归 61 项通过；新增真实 SQLite / D1 兼容查询与原子写入测试另通过，覆盖定时查询、领取、更新下次日期。
- 真实加密测试验证 Web Push payload 解密及 VAPID 签名；推送服务测试覆盖休息日、训练完成、时区 / 夏令时、发送失败重试及并发领取。
- 浏览器 320 / 393 宽度验收通过，清除状态后环立即移除。测试图片及状态仅在本机隔离账号保存。
- 发布前只读统计：线上已订阅设备为 0，私信提醒开启为 0；未读取设备 endpoint、用户身体记录或私信正文。
- 没有已授权的手机订阅可供实机送达验证。部署成功不等于已经验证某台手机的锁屏横幅；成员须添加主屏（iPhone）、开启通知、允许系统授权并点击测试通知确认。专注模式与网络可能影响及时送达。
