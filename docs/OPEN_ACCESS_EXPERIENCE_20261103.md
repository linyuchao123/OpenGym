# 公开注册与个人体验调整方案（2026-11-03）

状态：实现完成，公开注册及界面更新已发布。用户确认暂无抖音开放平台应用，先提供接入入口与站内可用配乐；头像和背景均支持裁剪。不要在聊天中收集应用密钥。

1. 公开注册：统一 Cloudflare config、密码注册、通行密钥 options/verify 的邀请开关。保留首次管理员引导，公开注册用户始终为普通成员。保留频率限制、重复昵称检查、现有账号与数据。测试无邀请码两种注册、旧密钥登录、并发注册及管理员权限边界。
2. 登录视觉：浅色默认，现有蓝色品牌；登录、注册、通行密钥作为清楚的入口。说明改为折叠帮助。首页提供浅色/深色/系统三选一。选择在设备保存，登录拉取账号设置后仍按本次明确选择显示；没有选择的旧账号保留原偏好。
3. 设置：移除“设置与数据→全部设置”的重复壳层，统一设置首页。账号卡使用与主页相同的 Avatar / useLifestyle 数据来源；按账号、外观、训练、通知、数据、帮助组织。保留旧路由兼容跳转，保留备份/恢复和管理员功能。
4. 通知：已有 Web Push 订阅、偏好、单次提醒和测试接口，并非完全未接入。requestPermission 当前直接由用户点击触发，因此不能仅凭截图认定手势丢失。需要逐项验证 PWA 安装状态、系统授权、service worker 就绪、订阅上传、服务端送达。按钮必须立即显示进行状态；超时和拒绝都有可操作说明；成功后可测试推送。iPhone 的实际系统送达需用户设备确认，浏览器模拟不能代替。
5. 背景编辑：拖动、双指缩放、缩放滑杆、复位；同一构图用于编辑器和主页。主页构图预览使用草稿，确认保存后提交，取消不更改原图。保留旧背景的默认居中显示。头像采用同一编辑器。
6. 社区音乐：发布时选择音频、截取片段、分别调整原声和配乐；作品下方显示唱片、歌名、作者/来源，实际播放时旋转，暂停停转，尊重减少动态效果设置。现有 MusicConnection 仅验证应用令牌及推荐接口，不能视为收藏/搜索已完成。先确认开放平台应用及具体权限；官方获批能力才能标为已接通。未获批时保留本站曲库和有权使用的自有音频体验，第三方入口明确接入状态，不用假歌曲、假收藏填充。
