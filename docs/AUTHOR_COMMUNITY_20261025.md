# 作者与共建社区（2026-10-25）

## 本批变更

- 首页按设备本地时间问候：00—05、23—24 夜深了；05—11 早上好；11—14 中午好；14—18 下午好；18—23 晚上好。分钟刷新，回到前台时更新。
- 首页右上角增加认识作者，作者介绍、开源归属、个人微信、公众号、共建群、GitHub、项目仓库、X、个人网站及邮箱以卡片展示。
- 新账号现有欢迎引导加入共建群邀请，确认后沿用账号同步的 welcomeVersion，不重复弹出。已有完成引导的账号不强制再次展示，可在设置与数据打开网站初心与新手指南。
- 更新日志只列出已实现的功能；Android 安装包制作中，iOS 开发者账号与经费准备中，未提供不存在的下载或商店入口。
- 普通用户首页和饮食页隐藏日常数据保存状态，仍保留失败、离线和待处理提醒及保存状态页面入口。管理员保留诊断详情。打卡页精简技术文字，不向普通用户直接展示坐标。
- 投稿信箱复用已认证反馈接口，后台显示服务端解析的昵称、账号编号、时间和正文；拒绝客户端伪造来源。现有每日 3 条限制不变。

## 素材和维护

用户提供的微信、公众号、群二维码及头像和网站截图原样保存于 frontend/public/author。未发布参考首页/打卡截图或其中的身体数据与位置。

共建群二维码标注 2026 年 11 月 1 日前有效。frontend/src/lib/author.js 集中保存到期时间；到期隐藏群码，保留作者微信备用联系。更新群码时应同时替换 community.jpg 和到期时间。图片点击打开原图，可保存识别；不保证微信内置浏览器能够直接唤起所有外部服务。

## 验证

前端 10 文件 100 项、Node API 23 项、Cloudflare 47 项回归通过。覆盖问候边界、二维码失效、欢迎确认/手动重开、普通用户保存警告、联系链接、反馈身份与管理员权限、既有训练和导航。

Chrome 390×844 手机尺寸检查首页、作者页、欢迎弹窗与更新日志；普通成员隔离环境提交反馈成功。未宣称 iOS/Android 真机测试已完成。本批不修改正式用户训练记录，不新增付费服务。
